# INTERLOCK frontend assets

This directory is reserved for rights-cleared, project-owned visual assets.

The approved local hero artwork is:

```text
frontend/assets/interlock_hero.png
```

The frontend uses that image automatically with a responsive left-side teal
overlay. If the file is unavailable, the existing CSS landscape/topographic
fallback remains available. The official logo assets are extracted from the
brand kit at:

```text
frontend/assets/canavan_atlantic_logo.png
frontend/assets/canavan_atlantic_logo_white.png
```

`frontend/assets/brand/canavan_atlantic_brand_kit.pdf` is the source/reference
asset. The screenshot under `frontend/assets/reference/` is design reference
only: it is never rendered by the application and is not used as a background.
Do not hotlink an image or add an unrelated stock image.
